⚙ Mehr Power: Der Installer

Diese Website kann alles umwandeln — der Installer installiert ein natives Windows-Programm, das mehr kann:

  • Rechtsklick im Explorer: jede Datei direkt konvertieren, ohne Browser zu öffnen
  • Ordner-Batch: ganze Ordner rekursiv auf einmal umwandeln (Rechtsklick auf Ordner)
  • Keine Größenbeschränkung — anders als beim Hochladen im Browser
  • Offline nutzbar, funktioniert auch ohne Internetverbindung
  • Selbst-extrahierende .exe: per Doppelklick auf eine konvertierte .exe wird die Originaldatei sofort wiederhergestellt

◈ Wie funktioniert das?

Eine "echte" 1:1-Umwandlung von z. B. einer Word-Datei in eine WAV-Audiodatei mit identischem Inhalt gibt es nicht — die Formate haben nichts gemeinsam. Stattdessen nutzt dieses Tool einen Universal File Container (UFC): Deine Originaldatei wird verlustfrei in einen technisch gültigen Container des Zielformats eingebettet — z. B. als eigener RIFF-Chunk in einer .wav, als Sequencer-Meta-Event in einer .mid, als zusätzliche Datei im ZIP-Container einer .docx, oder als Kommentarzeilen in einer .bat. Die Ausgabedatei funktioniert dabei tatsächlich als ihr Format (WAV spielt ab, BAT lässt sich ausführen, DOCX öffnet in Word) — und beim nächsten Umwandlungsschritt wird der Originalinhalt wiederhergestellt und neu verpackt. So bleibt der Inhalt über beliebig viele Umwege hinweg exakt erhalten.
